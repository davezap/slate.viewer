# Slate Viewer 0.43.0

- **No dead end in Settings → Spaces.** On a website where spaces of your own need a plan, an account without one no longer sees a space count and a Create space form that is then refused. It sees what a plan gives and a button to get one instead. It needs Metatrash 0.98.1.
- **No "Untitled" in the browser tab.** On the website the tab keeps the page's own title until the document has loaded, and the home page keeps the site's title instead of the file name.
- **A "…" on folders.** Point at a folder in Files and a "…" appears at the far right: it opens the folder's Properties. Properties is still on the right-click menu.
- **One New File and New Folder.** Right-clicking in Files offers New File, New Folder and Upload Files once, in the folder you clicked (or beside the file, or at the top of the space on empty space), instead of a second set for the root.
- The example in Settings → Spaces now reads "Acme Notes".
- Includes Slate 0.23.1, whose example theme is now `green.css`.
