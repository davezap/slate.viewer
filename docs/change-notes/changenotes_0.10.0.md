# Slate Viewer 0.10.0

## New

- **Locked files in Metatrash spaces.** Metatrash 0.46.0 lets a folder's `.metatrash.json` lock files with `readOnly`. A file locked for everyone opens locked, and it can't be renamed, moved or deleted (nor can a folder holding one) until you lift the lock in that `.metatrash.json`. Files locked only for agents stay editable for you.
