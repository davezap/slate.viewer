# Slate Viewer 0.34.0

- **Choose which agents a lock stops.** On a folder's **Properties > Security** page, each lock can now be for **folder actions** (the agents on the Automation page), for **connected agents** (Claude and other apps connected to your space), for all agents, or for everyone. Read-only files use the same choices.
- **Fill in forms and Take quizzes.** The same page decides who may send the folder's forms and quizzes. New spaces let agents fill in forms for the person they work for, and keep quizzes for people. An agent never signs a form.
- **Let an action send forms.** Under an action's **Limits and tools**, tick **Let it send forms in this folder**. The copy it files says an agent sent it, and a reviewer sees "sent by … (an agent)".
- Needs Metatrash 0.95.12.
