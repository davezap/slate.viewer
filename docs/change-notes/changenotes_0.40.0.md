# Slate Viewer 0.40.0

- **Your site's own wordmark in page footers.** Besides `:metatrash:`, a page footer can show the wordmark of the site you use, such as `:collumii:` on collumii.com. Folder Properties lists the ones your site offers under Page footer.
- **Best matches in Search.** Type a few words in any order and Search lists the notes that match them best, with their best lines. Switch to Exact text under the search box to find every line holding exactly what you typed.
