# Slate Viewer 0.8.0

## New

- **Manage files in the Files panel.** Right-click a note or folder to **Rename** (F2), **Duplicate** or **Delete** (Del) it. Delete asks first and moves it to the Recycle Bin, so you can get it back.
- **New Folder** on the right-click menu, in the File menu and as a third button in the Files header. Empty folders now show in the tree.
- **Drag to move.** Drag a note or folder onto another folder, or onto the empty space below the tree to move it to the top. Rest on a closed folder to open it.
- The open note follows a rename or move, unsaved changes included. Deleting it goes back to the note you had open before.
- In a Metatrash space, new names are made space-safe (`My Plan` becomes `my-plan.md`) and a rename or move keeps the note's history. Read-only spaces offer none of this, and the space's README stays where it is.
