# Slate Viewer 0.47.1

- **Quieter when you're signed out.** Visiting a site without signing in no longer asks for your forms to-do list, so the browser's console stays clean.
- **Bigger notes in spaces.** Slate Viewer now saves notes up to 1 MB to a space, up from 64 KB. A server can still set a smaller limit, and then it says so.
