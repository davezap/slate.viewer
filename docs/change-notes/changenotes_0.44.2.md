# Slate Viewer 0.44.2

- **Files shows a note's real name when it has two extensions.** `jobs.csv.md` is listed as `jobs.csv.md`, not `jobs.csv`, so it can be told apart from a real `jobs.csv` and renamed to it. A plain note such as `notes.md` still shows as `notes`. Quick Open and Search do the same.
- **Edit | Preview | Source stay on the right** for plain-text files such as a .csv, as they do for notes (Slate 0.24.2).
- **Show Hidden Files has a tick** in the right-click menu when it's on.
- File > New File keeps the whole name chosen in the dialog, so `jobs.csv.md` stays `jobs.csv.md`.
