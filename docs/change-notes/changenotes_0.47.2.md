# Slate Viewer 0.47.2

- **No more "save changes?" when you only read.** If the site briefly couldn't read a document you had open (for example while an agent was updating it), leaving the page could ask to save changes you never made. It doesn't any more.
- **No more conflicts with yourself.** While you kept typing after a save, the editor could mistake its own save for someone else's change and ask about a conflict. It now recognises its own saves.
- **New documents open at the top**, with their title in view.
- **Signing out keeps your place.** Signing in again takes you back to the page you were reading, not the docs home.
- **Diagrams show all their labels**, and Document Nav and links to a heading land on that heading even while diagrams above it are still drawing (Slate 0.26.1).
- **Clearer passkey message.** When "Use a passkey" finds none, it says so and what to do, instead of "Cancelled or timed out".
