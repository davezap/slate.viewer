# Slate Viewer 0.20.5

## Changed

- **New File and New Folder are named in the tree**, like Rename: the name box opens inside the folder the new file or folder goes in, at the top of its contents and indented to match, instead of above the whole tree. Enter makes it, Escape or clicking away cancels.
- **New empty folders reach the space.** With mtsync 0.66.0 (Metatrash 0.66.0), a folder made with New Folder in a space gets its `.metatrash.json` from mtsync and its `AGENTS.md` from the space, so it shows up for agents and other people straight away instead of waiting for its first file.
