# Slate Viewer 0.38.0

- **The website can carry its service's own name.** On a site that gives itself a brand, the header shows that name or wordmark and page titles end with it. On metatrash.com this is how the site becomes Collumii, built on the Metatrash core. The desktop app is unchanged.
- **A first visit to the website opens like a landing page.** The first time a browser opens the site, the sidebar panels start closed and Document Navigation is pinned beside the page, so the page itself has the room. Whatever you change after that is remembered as before.
- **Changes moved to the title bar on the website.** The ± Changes button is now in the title bar, next to Find, so a page you're reading has no toolbar above it. Ctrl+Shift+D still works, and the editing toolbar still appears when you turn Edit on. The desktop app keeps the button in its toolbar.
- Needs nothing new from the server. Metatrash's own website still says Metatrash.
