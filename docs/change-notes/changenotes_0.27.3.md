# Slate Viewer 0.27.3

- Keep the spelling, case, spaces, accents, emoji and punctuation you enter when creating or renaming notes and folders in Metatrash spaces.
- Accept the broader filenames supported by Metatrash Core 0.94.2, including ordinary dotfiles. Native Windows actions still reject names Windows cannot create.
- Wiki links prefer an exact case match and retain a fallback for older automatically slugged note names.
- Update Windows mtsync to 0.94.2 before using server filenames Windows cannot represent. It leaves those files online, reports the reason, and continues syncing compatible files.
