# Slate Viewer 0.18.0

## Changed

- **A quiz can cover several policies.** A quiz can now test a whole set of policies. Each policy is still confirmed with **I Have Read This**, and its bar also offers **Take the Quiz**. Reading a policy and passing its quiz are now separate.
- **A quiz has its own red dot.** It stays until you pass the quiz. Not passing, or waiting for a reviewer, keeps it.
- **Read first.** A quiz usually opens only once you've read the policies it covers. Until then its bar lists the ones still to read. A quiz can turn this off.
