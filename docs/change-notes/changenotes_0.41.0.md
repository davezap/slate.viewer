# Slate Viewer 0.41.0

- **Receive email in a folder.** Folder Properties › Automation has a new Receive email section. Tick it and save, and the folder gets its own email address: each message sent to it becomes a note in the folder, with its attachments beside it, and the folder's actions run on it. The address shows there with a Copy button (on the website). You can list who may send, block senders, choose whether replies keep the text they quote, and get a new address if the old one gets out.
- **Fixed:** saving a folder's properties no longer removes settings the dialog doesn't show, such as receiving email.
