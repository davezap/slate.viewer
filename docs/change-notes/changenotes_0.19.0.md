# Slate Viewer 0.19.0

## New

- **An image at the top of printouts.** A folder in a Metatrash space can name an image, such as your logo, to print centred at the top of the first page, above the title, on every document printed from that folder. Set its web address in the folder's Properties, on the Publishing page, under Printed copies. Subfolders that use their parent's settings get it too. Only the printout shows it; your files never change.
- The image is loaded when you print. If it can't be loaded within a few seconds, the document prints without it.
- The printout image can be locked on the Security page, like the other settings.

## Needs

- Metatrash 0.57.6 or later on the server: older servers refuse the new setting. Slate 0.19.5, included.
