# Slate Viewer 0.48.0

- **Choose a folder's order.** In a folder's Properties, General, Order in Files lists it Name A to Z or Name Z to A. Z to A suits names that start with a date, so the newest is on top. Subfolders always come first, and each folder chooses its own.
- **Run an action again on all its files.** After you change what a folder's agent is told to do, open the action on the Automation page and choose Run Again on All Files. You see how many files it covers and whose agent pays before anything runs. Up to 100 files, and it doesn't use up the folder's 20 jobs an hour. On the website.
- **Set what an invited person's apps may do before they accept.** On a space's Members page, each pending invitation has the same Apps: read and write or read only choice as a member, and they start with it when they accept.
- **Diagrams fit at any page zoom.** Mermaid diagrams no longer cut off their labels when the site is zoomed in or out (Slate 0.26.2).
