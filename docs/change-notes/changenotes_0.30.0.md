# Slate Viewer 0.30.0

- **See what's happening on metatrash.com.** The Files list now shows the work going on in a space instead of leaving you waiting for files to move.
- **Uploads show their progress.** Each file you drop or pick appears in Files at once: waiting, uploading with a percentage, then storing. If one fails it stays in red; click it to see why.
- **Conversions show their progress.** A PDF, Word, PowerPoint or Excel upload shows *queued*, then *converting* with a timer, then *moving…* while its Markdown page takes its place. The new page shows *✓ converted* for a few minutes. If a file can't be converted, or is left as it is (for example because `report.md` already exists), it says so; hover for the reason.
- **Folder actions.** Files that started an agent job show *agent waiting*, *agent running*, then *done*, *failed* or *skipped*.
- **Who's here.** The initials of other people with the space open show at the top of Files, and beside the file they are reading.
- A line at the top of Files sums it up, and a folder with work inside shows a small spinner while it's closed.
- This is on the website for now. Slate Viewer on your computer gets it in a later release.
