# Slate Viewer 0.27.0

## New

- **Monthly or yearly on the pricing page.** When the server offers yearly billing (Metatrash 0.93.0), the pricing page has a Monthly / Yearly switch. Yearly is ten times the monthly price, so two months free, with the same 30-day trial. Extra storage on a yearly plan is billed yearly too.
- **Settings → Billing knows the cycle.** It says "billed yearly" for a yearly plan, and the storage price check talks about the year instead of the month.
