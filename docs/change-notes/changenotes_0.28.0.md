# Slate Viewer 0.28.0

- **Convert to Markdown** now gives you an editable page in place of the original: `report.md` takes the PDF's place, and the PDF moves into an `assets/` folder beside it. The Markdown starts with an **Open original PDF** link, so the readable, editable page is what you open, and the original is one click away on the desktop and the website. The move keeps the original's history.
- PDFs on servers with Docling conversion read with real headings, tables and text from scanned pages, so Convert to Markdown gives a much better starting point.
