# Slate Viewer 0.29.0

- **Upload files by dragging them in.** Drop files from Explorer, Finder or your desktop onto the Files list. They go into the folder you drop them on, or the folder of the file you drop them on, or the top of the space. This works in Slate Viewer and on metatrash.com.
- **Upload Files…** on the right-click menu puts files you pick into that folder or into the top of the space.
- Nothing is replaced: if the name is already taken, the new file gets ` (2)`, ` (3)` and so on.
- On metatrash.com, an uploaded PDF, Word, PowerPoint or Excel file becomes a readable Markdown page a few minutes later, and the original moves into an `assets/` folder beside it. The page's first line opens the original.
