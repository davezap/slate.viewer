# Slate Viewer 0.34.3

Links to a heading now work from the address bar. An address such as
`metatrash.com/spaces/owner/space/notes.md#Run%20it%20from%20Windows%20(PowerShell)`
or `notes.md#run-it-from-windows-powershell` opens the document at that heading,
instead of where you last left it. Following a heading link, or clicking a
heading in the outline, also puts the heading in the address bar, so you can
copy the address to send someone straight to that part of the document.
