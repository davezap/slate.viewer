# Slate Viewer 0.39.0

- **A folder's footer can have up to three lines.** In Folder Properties → Publishing the footer box now takes several lines: press Enter to start a new one. Each line is centred under the page on its own, so links such as Terms and Privacy can sit on a line of their own. Needs Metatrash 0.95.29 or later; an older server still accepts only one line.
- **Changing between light and dark fades.** Choosing a theme, or your system switching between light and dark while the app is open, now fades the colours over a moment instead of flipping at once. If your system asks for reduced motion, the change is instant as before.
