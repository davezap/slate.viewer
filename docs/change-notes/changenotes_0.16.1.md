# Slate Viewer 0.16.1

## Changed

- **Sending a form counts as reading it.** If a form is in a folder that asks people to read its files, sending it now confirms you read it, so you don't also have to choose I Have Read This. Its dot goes and the bar says which version it counted for.

## Fixed

- **No extra space at the top.** A document that starts with front matter or a comment no longer has a gap above its first heading in Preview.
