# Slate Viewer 0.33.0

- **Easier-to-read folders.** An open folder's files and folders hang from a line under its arrow, so you can see at a glance which folder a file such as `.metatrash.json` belongs to.
- **Folder settings by name.** Type `.metatrash.json` as a new file's name and the folder's Properties open, instead of a new note being made. Every folder in a space already has its settings.
- **Folder links work.** On the website, right-click a folder and choose **Copy Address**: the address now ends in a slash, so it opens the folder instead of "not found". Metatrash 0.95.11 also opens folder addresses typed without the slash.
