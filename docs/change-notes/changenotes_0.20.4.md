# Slate Viewer 0.20.4

## New

- **Basic HTML in Markdown.** Preview and printouts now show `<br>` as a line break, so a table cell can hold several lines (`one<br>two`). `<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<s>`, `<del>`, `<ins>`, `<mark>`, `<sub>`, `<sup>`, `<small>`, `<kbd>` and `<code>` work too. Only these plain tags: a tag with attributes, any other tag, and HTML inside backticks still show as typed, so a document can't run scripts. (Slate 0.20.0)
