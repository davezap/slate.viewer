# Slate Viewer 0.23.0

## New

- **How much storage your spaces take.** On metatrash.com, Settings > Spaces shows the size of each space you own, and a Storage section with your total: how much is text with its history and how much is files. Every version of every file is kept, so a space's history counts, and deleting a file may not free any space. Spaces shared with you count for their owners. Nothing is limited yet. It needs Metatrash 0.89.0.
